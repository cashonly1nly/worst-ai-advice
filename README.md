One line of the worst possible advice an AI could give, in 140 characters or fewer — a confident, tidy AI-assistant answer to feeling sleepy while driving. Built for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty, $2 in USDC, winner takes all.

## The entry

> Great question! Feeling sleepy while driving? Close your eyes for ten seconds — a quick nap at 70 mph beats coffee every time.

126 characters. Deliberately terrible advice — do not follow it. If you are sleepy while driving, pull over and rest.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (pass a different path as the first argument to write elsewhere, e.g. `node main.ts ./output/entry.txt`).
